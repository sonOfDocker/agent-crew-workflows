# Expected Workflow Artifacts

This document describes the artifacts generated by the [Story Workflow Golden Path Demo](../README.md).

## Artifact Contract

The workflow follows a strict artifact contract. Every run produces the following six files:

### 1. `story-refinement.md`
- **Purpose**: Refines the input story for clarity and completeness.
- **Key Sections**: Source Story Summary, Refined Story Summary, Requirements, Acceptance Criteria Review, Assumptions, Open Questions, Out of Scope, Readiness Assessment.
- **Guardrail**: Must include a human review warning.

### 2. `architecture-notes.md`
- **Purpose**: Provides architectural guidance and identifies impact.
- **Key Sections**: Architecture Summary, Relevant Context, Impacted Areas, Proposed Approach, Risks and Tradeoffs, Documentation Impact.
- **Guardrail**: Must distinguish between evidence and recommendations.

### 3. `test-plan.md`
- **Purpose**: Outlines the validation strategy.
- **Key Sections**: Test Strategy Summary, Acceptance Criteria Mapping, Required Tests, Edge Cases, Suggested Test Commands.
- **Guardrail**: Must map tests back to original acceptance criteria.

### 4. `implementation-plan.md`
- **Purpose**: Details the planned implementation steps.
- **Key Sections**: Implementation Summary, Planned File Changes, Step-by-Step Plan, Test Execution Plan, Risks and Blockers.
- **Guardrail**: Must state that human approval is needed before changes.

### 5. `review-notes.md`
- **Purpose**: An agent-led review of the generated plans.
- **Key Sections**: Review Summary, Artifacts Reviewed, Acceptance Criteria Status, Evidence Reviewed, Issues Found, Final Recommendation.
- **Guardrail**: Must list what evidence was available (or none).

### 6. `final-summary.md`
- **Purpose**: High-level summary of the entire run.
- **Key Sections**: Workflow Run Summary, Inputs Used, Artifacts Generated, Key Findings, Open Questions, **Required Human Actions**, Limitations, Recommended Next Step.
- **Guardrail**: Must surface required human actions and next steps.

## Sample Guardrail Warning

Every artifact should contain a warning similar to this:

> **Note**: This artifact is AI-generated planning support. It is not proof of implementation, test success, or story completion. Human review is required.
